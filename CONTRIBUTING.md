# Contributing

Read the constitution and active increment before changing code. Keep FAB IDs stable;
update the owning spec/plan/tasks and acceptance record together. Preserve native
S-CORE ownership and use the source lock for discovery. Build references only in
disposable copies. A dependency update needs a compatibility/migration report.

Run the checks in README.md. Report failures, skipped prerequisites and fixture origins
honestly. Use small, reviewable changes. The foundation contracts are proposals for
review, not accepted engineering decisions. Follow the existing Apache-2.0 license
and retain third-party notices. Do not publish upstream artifacts without authorization.
