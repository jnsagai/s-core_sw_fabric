# Output binding

The caller supplies the exact output schema and native artifact destination. Keep native IDs,
source revisions, license notices and existing status values. A valid-looking agent_result or
content digest is a draft/byte-identity record, not trusted evidence or acceptance. A native
rationale may be required inside the artifact; the intermediate stage result remains structured.
Missing required fields or an unavailable bounded query tool stop drafting and report the gap.
Do not load historical raw logs or the complete S-CORE process to infer missing authority.
