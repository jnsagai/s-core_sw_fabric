# Built-in specification quality checklist

Maintained by speckit-specify on 2026-10-03. These are requirements-quality checks,
not implementation acceptance or engineering/human approval.

- [x] Each story has independently measurable acceptance scenarios.
- [x] Requirements have stable IDs and trace to the owner brief/US scenarios.
- [x] Context ceilings and unknown/stale/error outcomes are explicit.
- [x] Provider measurements are distinguished from offline estimates.
- [x] Native authority, historical evidence and human decisions remain preserved.
- [x] No material specification ambiguity requires user clarification.
