## Native capability limits

- Demonstrated: register, create, start, inspect, events, timeline, questions, stage list,
  stage output, blobs, cancel. Run listing, answers, approval, `/retry` and `/state` are not
  capabilities.
- **Not demonstrated:** explicit same-run resume. It returns 200, appends resume/runnable records,
  and does not continue (`run already finished already — nothing to resume`). The fabric treats
  the resulting stream as `NATIVE_STATE_CONFLICT`.
- Native restart hazards: a graceful stop can leave a command running after `failed/terminated`;
  a crash triggers automatic startup continuation that re-executes the in-flight step, and a
  surviving worker can produce contradictory terminal records. Stage IDs stay `@1`.
- No run-create idempotency key: a lost create response stops at `reconciliation_required`.
- Native `/retry` creates a new fork run that repeats effects; one was sent unintentionally by a
  probe on a disposable probe-only run (recorded in acceptance). No fabric path sends it.
- Native dump is not a closed record (no version file map, blobs or digest manifest).
