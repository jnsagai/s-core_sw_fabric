# ADR 0014: Bounded context and lazy procedural Skills

Date: 2026-10-03. Status: Proposed for owner review; local implementation under 011.

## Decision

Deterministic impact and freshness narrow baseline-bound agent context. Raw evidence remains
unchanged outside conversation history. Model-facing tools provide exact bounded findings,
summary previews, pagination and checksum refs, with per-result and aggregate budgets.
Generic evidence reads and broad grep are denied; source retrieval is manifest-bound.
Native blocking command hooks enforce admission, with a separately configured bounded stdio
service. Do not assume a post-tool hook can rewrite native tool output.

Skills describe one activity. Select and render only digest-bound procedures; retrieve declared
references explicitly. A Codex Skill installation does not prove Fabro runtime availability.
Static role/authority/tool instructions precede dynamic tasks. Autonomous stages return structured
results without execution narration; authoritative artifact rationale remains intact.

Operational class budgets narrow existing absolute role/model ceilings and 007 admission.
Unknown usage blocks continuation. Critique/escalation uses explicit triggers; no automatic
premium fallback, approval or second scheduler is introduced. Five derived workflow modes keep
all mandatory checks and human gates. Existing v1 replay and historical runs remain valid.

## Consequences and unresolved qualification

Malformed, oversized, stale, unknown or unsupported input refuses optimization. Complete evidence,
source/status/license identities and human authority remain preserved. Existing queues are not
migrated. Offline fixture byte/token estimates do not establish provider-cache/cost savings.
An explicitly authorized disposable Flash experiment qualifies pinned native guard/service
wiring and records ten real calls over development fixtures. It measured 30.46–30.63% uncached
input reduction, below the 60–80% target. Optional transport projection now removes tool
declarations already denied by the guard, preserving messages and selected schemas; its replay
is retained offline. A separately authorized ten-call comparison of unchanged fixture prompts
with equal tool selection measures 66.32–66.60% uncached reduction and equivalent outputs;
[projection evidence](../../specs/011-change-impact-and-freshness/evidence/projection-qualification/README.md)
retains both payloads and reconciled native/provider usage. Real engineering qualification
and owner ratification remain pending; default live policy remains disabled. These
observations cannot accept real S-CORE engineering artifacts.
